# Free Radio — visual directions

Three initial native iOS concepts, each showing Stations and Player. No application code has been started. Choose a direction before developing a coding plan.

## Directions

- A / Grid: warm white, black, olive. Simple station rows and artwork-led player.
- B / Apex: charcoal, white, acid lime. Numbered station presets and oversized racing-inspired typography. Recommended starting point for the requested DIRT feel.
- C / Signal: ivory, black, vermilion. Pinned station tiles and song-first player composition.

## Shared intended behavior

- Two tabs: Stations and Player.
- Stations supports search, pin/unpin, locally saved stations, and a compact current-player bar.
- No login. Pinned stations persist on the device.
- Player shows station, live state, album artwork when available, artist/band, and song title.
- Primary playback control toggles Play/Pause; Stop is a separate control. Volume has a slider.
- The mockups depict active playback, hence the visible Pause icon.
- These are live-radio concepts without song seeking or previous/next track controls.
- Station and song names and artwork in these concepts are illustrative.
- When artwork or song metadata is unavailable, the intended fallback is station artwork or a designed placeholder and a clear 'Track information unavailable' message. Data-source feasibility will be assessed during planning.
- Final implementation should accommodate long titles and accessibility text sizes; these raster concepts do not validate those behaviors.

## Reference

[Design Daily #6: Dark and Light mode Audiobook Media Player, Ahmad Mizan Nur Haq](https://dribbble.com/shots/25881550-Design-Daily-6-Dark-and-Light-mode-Audiobook-Media-Player)

The reference informed the restrained palette, prominent artwork and circular controls. The user's DIRT inspiration informed the oversized Swiss sans-serif typography.
